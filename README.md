# Task Tracker Mini Project

A simple full-stack Task Tracker application to combine frontend and backend knowledge. 

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: In-memory data store

## How to Run It

1. **Install Dependencies**
   Make sure you have [Node.js](https://nodejs.org/) installed, then open your terminal in this project directory and run:
   ```bash
   npm install
   ```

2. **Start the Server**
   Run the following command to start the backend server:
   ```bash
   node server.js
   ```

3. **Open the App**
   Open your web browser and navigate to:
   [http://localhost:3000](http://localhost:3000)

## Features
- View all tasks
- Add a new task
- Mark tasks as completed
- Delete tasks
